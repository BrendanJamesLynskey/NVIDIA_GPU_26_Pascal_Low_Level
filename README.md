# Inside Pascal — The First HBM and NVLink GPU

A low-level look at NVIDIA's 2016 Pascal architecture — GP100 (P100, the first commercial HBM2 + NVLink GPU) and GP102/104/106 (GTX 10 series, GDDR5X). Block diagrams, the FP-heavy GP100 SM, FP16x2 packed math, TSMC 16FF+ process, voltages and clocks, HBM2 packaging and GDDR5X memory, NVLink 1.0 (4 links × 20 GB/s), and the innovations Pascal put on the map. Includes an interactive SKU picker.
